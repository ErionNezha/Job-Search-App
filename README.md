# Punë Shqip

Kërko, filtro dhe gjurmo aplikimet për punë — me të dhëna demo në shqip.

## Veçori

- 💼 **12 punë demo** — titull, kompani, qytet (Tiranë/Durrës/Prishtinë/Remote), kategori, tip, pagë €, përshkrim, datë
- 🔍 **Toolbar filtrimi** — kërkim (titull/kompani), kategori, tip, qytet, renditje (Më të rejat / Paga zbritëse)
- 🔖 **Ruaj** — toggle ruajtjeje me tab "Të ruajtura"
- 📝 **Apliko tani** — krijon aplikim me statusin "E dërguar"
- 📊 **Gjurmim aplikimesh** — statuset: E dërguar → Në shqyrtim → Intervistë → Pranuar / I refuzuar, me butonat "Përparo →" dhe "Refuzo"
- 📈 **Statistika** — nr aplikimesh, nr intervistash, nr të ruajtura
- 💾 **localStorage** — ruajtjet dhe aplikimet ruhen mes sesioneve
- 💻 **Kodi burim** — tabs HTML/CSS/JS me kopjim, direkt në faqe
